# Stat 238 Homework

Code for my homework in **Stat 238** at **UC Berkeley**.

This repository contains selected coursework in Bayesian statistics, with assignments focused on posterior inference, hierarchical modeling, regression, MCMC, and applied data analysis in Python.

## Topics

- `hw1`: Bayesian credible intervals, confidence interval coverage, truncated and censored data, and robust modeling with Laplace-style likelihoods.
- `hw2`: Conjugate Bayesian models, posterior computation for binomial data, empirical Bayes shrinkage, and hierarchical modeling with real-world rate data.
- `hw3`: Classical and Bayesian bootstrap methods, hierarchical beta-binomial modeling, Bayesian text classification, and simple language modeling.
- `hw4`: Logistic and probit regression, Laplace approximation, robust regression, changepoint and spline-style regression, and Bayesian smoothing for time series.
- `hw5`: Metropolis-Hastings and Gibbs sampling, Laplace approximations, Bayesian generalized linear models, hierarchical normal models, and posterior inference for structured regression problems.

## Tools

Python, NumPy, SciPy, Matplotlib, Statsmodels, and PyMC.
